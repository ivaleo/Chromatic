Самое дорогое место — 260 строк прозы про кампанию в ℝ⁶. Девять десятых этого

единственный содержательно новый механизм в разделе); (в) почему фикс-метрический

## Часть II. Разбор языка

### Диагноз: проблема не в длине фраз, а в регистре

Я померил: средняя длина предложения — 19,5 слов, длиннее 40 слов — всего 6
предложений из 270. По этим меркам текст нормальный. Ощущение «машинности»
создают три других вещи.

**1. Протокольный регистр в §3.1 и §9.** Цепочки «Затем… Далее… Для X проверено
Y» сообщают действие и число, но не сообщают связи: почему этот шаг следовал из
предыдущего и что он дал понять. Читатель не может отличить решение автора от
следствия расчёта.

> **Было.** «Внешний PSD-master, плотное дискретно-непрерывное чередование и
> соседние арифметические острова теперь сходятся к одному локальному барьеру.
> Поэтому 336 остаётся основной численной целью в ℝ⁶, но следующий шаг должен
> искать другие родительские L-type-конусы и связывать период с формой.»
>
> **Предлагаю.** «Три независимых подхода — внешняя полуопределённая релаксация,
> попеременная оптимизация ядра и формы и перебор соседних арифметических типов
> — упираются в один и тот же барьер D/diam ≈ 0,9842. Это говорит о том, что
> препятствие не в качестве локальной оптимизации: внутри текущего вторичного
> конуса лучшей формы, по-видимому, нет. Поэтому дальше нужно менять сам конус,
> согласуя выбор периода с выбором формы.»

**2. Нанизывание определений.** «для каждого допустимого малого проективного
ряда», «двойственных проекционных сертификатов», «фиксированного периодического
унимодулярного разбиения» — по три-четыре определения на существительное.
Английский это терпит, русский почти нет.

> **Было.** «Чтобы перескочить локальные потолки при 134 = 67·2, мы
> максимизировали вторую порядковую статистику двух точных ядер и получили
> мостовую метрику. Исчерпывающий пороговый оракул на этой форме при пороге 0,90
> нашёл 28 новых ядер — по одному свидетельству для каждого допустимого малого
> проективного ряда.»
>
> **Предлагаю.** «Локальный максимум при 134 = 67·2 удалось обойти так. Вместо
> ширины одного ядра мы максимизировали вторую по величине из ширин двух ядер
> сразу: полученная форма Грама хороша не для одного из них, а для обоих. На
> этой форме исчерпывающий перебор с порогом 0,90 дал 28 новых пригодных ядер —
> по одному на каждую допустимую строку проективного пространства.»

Заодно исчезает «мостовая метрика»: термин, который вводится одним
словосочетанием и больше нигде не объясняется.

**3. Непереведённая терминология.** Около сорока терминов идут латиницей или
калькой прямо в русской фразе. Предлагаемые замены:

| Сейчас | Предлагаю |
|---|---|
| active-set доводка | доводка по активному набору |
| all-values поиск | перебор всех значений |
| pair-lookahead / metric-lookahead | просмотр на шаг вперёд по парам / по метрике |
| best-response | наилучший ответ |
| successive halving | последовательное отсеивание |
| set-cover LP/MIP | ЛП/ЦЛП покрытия множества |
| maximum-weight pricing | генерация столбцов максимального веса |
| cutting-plane | метод отсекающих плоскостей |
| soft-min | сглаженный минимум |
| master-решатель, PSD-master | ведущая задача |
| bitset-оракул | оракул на битовых масках |
| RREF-шаблоны | шаблоны ступенчатого вида |
| source-preserving индексы | индексы, сохраняющие исходный характер |
| determinant-repair | доводка определителя |
| не-косетный период | период не по классам смежности |
| «раздутый K» | полный многодольный граф |
| UNSAT / UNKNOWN / LIMIT | невыполнимо / не установлено / предел времени |
| **первичный** (Radon-поиск, блоки, компоненты) | **примарный** — здесь это калька с *primary*, и «первичный» читается как «предварительный» |

Метафоры, которые стоит либо определить одной фразой при первом употреблении,
либо убрать: «бассейн», «локальный потолок», «фронтир», «острова», «скобки» (в
смысле двусторонней оценки), «дожим».

### Отдельно: два места, где стиль переходит в смысл

**«Убитые» векторы.** В строке 471 `killed(B,k)` определено как число **не**
отделённых векторов (его минимизируют), а в строке 651 сказано: «число векторов,
**убитых** строкой a, есть ℛh(a) = Σ_{a·x=0} h(x)». Но эта сумма считает как раз
векторы, попавшие в ядро, то есть **не** отделённые строкой a. Фраза написана с
обратным смыслом, а следующее предложение — «FFT даёт глобально лучший ход» — не
уточняет, минимум это или максимум. Для центрального механизма результата в ℝ⁷
это надо переписать: «ℛh(a) — число запрещённых векторов, которые строка a **не**
отделяет; один n-мерный БПФ даёт значения ℛh сразу для всех строк, и лучший ход —
это argmin».

**Клеточные раскраски, пункты (ii) и (iii).** Пункт (ii) утверждает, что H_{Λ'} —
полный граф K₁₄₀, то есть клика равна 140; пункт (iii) сообщает «клика графа
конфликтов равна 80 в ℝ⁵». Речь о разных графах (во втором случае — об
измельчённом периоде), но из текста это не следует, и абзац читается как
противоречие. Там же сломан синтаксис: «(для всякого v ∈ F и максимальное
расстояние между ячейками D′(v) ≥ 2R, проверено по вершинам ячейки)».

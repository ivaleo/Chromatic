## Что сделано, кроме упрощений

- **Найден и исправлен дефект миграции 088288c** («единая параметризация
  форм Грама»): в 11 скриптах кампаний остались вызовы `unpack(x)` без `dim`
  и `norm_gram(B, n)` с лишним аргументом — 20 вызовов, каждый падал
  `TypeError` при запуске (импорт-тест этого не ловил). Восстановлено
  поведение до миграции: `unpack(x, 4)` (`o2_r3` — 3), `norm_gram(B)`;
  искалеченная конструкция в `csp_sweep5d.py` свёрнута.
- `sweep.py`, `verify2.py` писали результаты в захардкоженный путь
  scratchpad прежней сессии — заменено на `results_path(...)`
  (артефакты `sweep_results.json`/`verify2_results.json` лежат в `results/`).
- 28 конструкций `json.load(open(results_path(X)))` (дескриптор не
  закрывался) → `paths.load_json(X)`; инлайн-копии `pack`/`norm_gram` в
  `q_frontier.py`, `cma_form.py` → импорт из `forms`.
- `combigeo/src/bigdim.cpp`, `forbidden_coords`: агент заменил `D < x`
  на ранний `continue` при `D >= x`; для `D = NaN` это расходится —
  возвращено `!(D < x)`.
- В `verify_main_results.py` агент «исправил» числа в комментариях
  (17,7 млн → 46,1 млн; ~1,5 ч → ~3 ч) и текст `--help`; источники
  (`WORK-2026-09-07-dim9-7203.md`, `RESULTS.md`) подтверждают исходные
  значения — возвращены.
- Удалены две неиспользуемые функции точной арифметики в
  `dim7_1029_exact.py` (`tangent_extreme_rays_exact`,
  `next_vertex_along_ray_exact`, 91 строка, ноль ссылок во всём репо;
  полнота доказывается замыканием по (N−1)-подмножествам). Прогон dim7
  до/после — идентичный JSON. Если они держались как альтернативный
  маршрут аудита — откат одним `git checkout` файла.
- `Makefile`: подсказка `make test` говорила «199 passed», фактически 572.

## 4. Дешёвые усиления — новые результаты за дни

### 4.1 Планарная теорема для эйзенштейновых конструкций (½ открытого вопроса 7)

**Утверждение.** Для любой эйзенштейновой решётки $\Lambda$ (ℤ[ω]-модуль) и
$\Gamma=(3+\omega)\Lambda$: $D(\Gamma)\ \ge\ \sqrt{7/3}\,\lambda_1(\Lambda)$.

**Доказательство (эскиз).** Каждый вектор $\Gamma$ есть $v=(3+\omega)w$,
$w\in\Lambda$. Векторы $\pm w,\ \pm\omega w,\ \pm(1+\omega)w$ лежат в $\Lambda$
и имеют одну норму $\|w\|$ (умножения на единицы $ℤ[\omega]$); их шесть
полупространств $\langle x,u\rangle\le\|u\|^2/2$ содержат $V_0$ и высекают в
плоскости $P=\mathrm{span}(w,\omega w)$ правильный шестиугольник $H$ — ячейку
Вороного решётки $ℤ[\omega]w\cong A_2$ масштаба $\|w\|$. Нормали всех шести
лежат в $P$, поэтому ортопроекция $\pi_P(V_0)\subseteq H$, и
$\mathrm{dist}(v/2,V_0)\ \ge\ \mathrm{dist}_P\!\big((3+\omega)w/2,\ H\big) = \sqrt{7/12}\,\|w\|$
(двумерная выкладка: точка $(1.25,\ \sqrt3/4)\|w\|$ против вершины
$(0.5,\ 1/(2\sqrt3))\|w\|$). Значит $D(v)\ge\sqrt{7/3}\,\|w\|\ge\sqrt{7/3}\,\lambda_1$. ∎

**Следствия.**
- $D_{\min}=\sqrt7$ для $(3+\omega)E_8$, $(3+\omega)E_6^*$ и горизонтального
  пола ламинирования — теперь **[Т]**, а не численная проверка 240 векторов.
- Неравенство «≥» в тождестве (eq:eis) доказано для *всех* эйзенштейновых
  решёток; открытым остаётся только вопрос равенства (когда шестиугольник
  вписан в $V_0$; для решёток, где минимальные векторы порождают, — видимо,
  всегда).
- $\chi\big(\R^{24},[1,\sqrt{7/6}\,)\big)\le 7^{12}$ — **строго** (классическая
  часть — АБПР, ширина — новое; нужно только известное $2R/\lambda_1=\sqrt2$
  для решётки Лича).

### 4.2 $K_{12}$: немедленное улучшение ширины в $\R^{12}$

Правило $d=2/\rho$ (prop:mult, теперь полностью [Т]) применимо к Коксетеру–Тодду:
$\rho(K_{12})=\sqrt{8/3}\approx1.633\le2$, значит

$$\chi\big(\R^{12},[1,\ell]\big)\le 3^{12}\quad\text{при }\ell<2/\sqrt{8/3}=\sqrt{3/2}=1.224745.$$

Это тот же индекс $3^{12}$, но ширина $1.2247$ вместо $1.0755$ у башни — и все
константы ($\lambda_1$, $R$) для $K_{12}$ известны точно из литературы. Проект
использовал $K_{12}$ только как отрицательный пример эйзенштейнова пути и
пропустил её как *вещественный* носитель. Бесплатный строгий результат.

### 4.3 ρ-скан каталога решёток для n=9–12

Измеренные значения башни подозрительно точны: $d_{10}=1.224745=\sqrt{3/2}$
(т.е. $R^2/\lambda_1^2=2/3$ у $\Lambda_{10}$), $d_{11}=1.154701=2/\sqrt3$
($R^2/\lambda_1^2=3/4$ у $\Lambda_{11}$). Радиусы покрытия ламинированных
решёток малых размерностей табулированы (SPLAG, гл. 6); если точные значения
подтверждаются литературой — строгие ширины n=10,11 поднимаются с
1.1795/1.1166 до 1.2247/1.1547 **без вычислений**. Плюс общий скан: по
каталогу Небе–Слоэна прогнать $\rho=2R/\lambda_1$ для всех решёток n=9..12
(и сечений $K_{12}$ для n=10,11) — каждая с $\rho<$ текущего даёт улучшение
ширины при индексе $3^n$.

### 4.4 [Ч]→[С] для 9604, лестницы и башни

Ключевое наблюдение: во всех этих конструкциях $t^2$ рационально (0.8649,
0.4761, 3/8, …), сдвиг $c$ рационализуем, значит **матрица Грама рациональна**.
Тогда: λ₁ и D_min — точный Финке–Похст в рациональной арифметике; слоевые
векторы — $D(v)=2\,\mathrm{dist}(v/2,V_0)$ — это QP по рациональным
полупространствам, дуальные множители дают точный сертификат (машинерия
уровня ℝ⁵/132 уже есть, вершины ячейки НЕ нужны); diam — по строгой (P1),
без радиуса покрытия. Итого вся цепочка строгих ширин переводится в [С]
существующими инструментами. Это же снимает рассинхрон статусов из §2.3.

## 5. Главный замок: сертификат радиуса покрытия в 9D — план вскрытия

Судьба 7203 (и строгость измеренного 1.0478 при 9604/t=1) упирается в одно
число — верхнюю границу $R(\Lambda)$ слоёной решётки. Ветвление по $S^8$ и
перечисление Делоне закрыты (экспоненциальны). Но слоёная структура даёт
точную декомпозицию, которую проект ещё не пробовал:

$$R(\Lambda)^2=\max_{x,\ z\in[0,t]}\ \min_{i\in\{-1,0,1,2\}}\Big[\underbrace{\mathrm{dist}^2(x-ic,\ E_8)}_{f(x-ic)}+(z-it)^2\Big].$$

- $f(y)=\|y-\lambda(y)\|^2$ кусочно-квадратична на **известном** разбиении
  Вороного $E_8$ (240 фасет, всё табулировано);
- арена задачи — общий рефайнмент двух (четырёх) сдвинутых копий разбиения:
  куски $V(\lambda)\cap(V(\mu)+c)$, перечисляются по разностям $\mu-\lambda$
  в шаре радиуса $\lesssim 2R+\|c\|$ (Финке–Похст, ~10³–10⁴ кусков);
- на каждом куске «поверхность равенства» двух квадрик — **гиперплоскость**
  (квадратичные члены сокращаются), т.е. max–min решается точным QP с
  рациональными сертификатами покусочно.

Объём работ — масштаб уже пройденного exact-аудита ℝ⁵ (сотни LP/QP в 8D), а не
$9!$ ячеек Делоне. Выигрыши: (а) решается 7203 — либо $\chi(\R^9)\le7203$,
либо честное закрытие кандидата; (б) строгая ширина 1.0478 у 9604;
(в) рекурсивное применение к башне заменяет рекуррентную оценку точным $R$ и
поднимает строгие ширины n=10–12 до измеренных.

## 6. Новые механизмы поиска раскрасок, 4–12

### 6.1 Размерность 4 (предел 45 в решёточном классе)

Три независимые линии свидетельств (CMA-лестница, NM-дожим, best_killed=1)
говорят: внутри решёточно-косетного класса ниже 45 пути нет. Менять класс:

- **(a) Подъячеечные раскраски** — по собственному выводу проекта
  «единственный оставшийся путь»: цвет не постоянен на ячейке. Конвейер:
  разрезы ячеек чемпиона гиперплоскостями → граф конфликтов кусков (точные
  расстояния между политопами через GJK из combigeo) → CP-SAT-раскраска с
  CEGAR. Валидация в 3D (попытка побить BCC/15 — ожидаемо провалится, это
  контроль корректности), затем цель 44 в 4D.
- **(b) Периодические не-решёточные родители**: Delone-множества с s>1
  точками на период (лемма Иванова обобщается: $D(v)=2\,\mathrm{dist}(v/2,V_0)$
  заменяется на min по парам ячеек). Поиск при s=2,3 тем же
  min-conflicts/CP-SAT. Класс строго шире решёточного и в 4D не исследован.
- **(c) Доказательные полы**: Fourier/LP-машинерия (d6_torus_fourier_lp) уже
  умеет $\vartheta$ на торических графах Кэли — применить в 4D, чтобы
  превращать экраны в теоремы «для данного периода ниже k нельзя» ([Э]→[Т]
  для класса периодов).

### 6.2 Размерности 5–7

- **336 в ℝ⁶ — приоритетная цель** (разрыв 1.576%); план ODC v2 из
  NEXT_MECHANISM (банк L-type конусов + pricing) верен, добавить нечего,
  кроме приоритета.
- **Эрмитова деформация**: гибрид 336 разрушает эйзенштейнову структуру, а
  можно деформировать *внутри* неё — CMA по эрмитовым формам над ℤ[ω]
  (для ранга 3 это 9-параметрическое пространство вместо 21): планарная
  теорема §4.1 держит $D\ge\sqrt{7/3}\lambda_1$ **точно вдоль всей деформации**,
  оптимизируется только $\rho$. Не исследовано; тот же приём в 4D
  (ранг 2, $D_4$) и 8D (ранг 4, $E_8$).
- **Лотерейный билет: ламинирование E₆*→ℝ⁷ при m=3, индекс 1029 < 1323.**
  Бюджетная арифметика 9D (слоям нужно $t\gtrsim1.15$, строгий диаметр требует
  $t\le1$) — против, но она выведена из структуры дыр $E_8$; у $E_6^*$ дыры
  другие (и $r_2$ может быть меньше 1.5). Проверка — часы на существующем
  `lamination.py` (сменить базу), выигрыш — 22% и новый рекорд ℝ⁷.
- **Lamination sweep**: прогнать все (база, m) с бюджетным критерием
  $m\cdot t\gtrsim1.3\,\mathrm{diam}$ vs $t\le\mathrm{diam}\sqrt{d^2-1}$ —
  почти всё закрывается на бумаге (49·4=196>132, 140·4=560>343, 343·4=1372>1323),
  единственный просвет — E₆*/m=3 выше.

### 6.3 Размерность 8

### 6.4 Размерность 9

решётке**; Minkowski-скрин для альтернативных 9D родителей (включая

### 6.5 Размерности 10–12

- **Ранг-5/6 эйзенштейнов генус — главная ставка.** Отрицательный результат
  проекта покрывает только Construction-A (тернарные коды + Синглтон);
  произвольные эрмитовы ℤ[ω]-решётки ранга 5 с $\rho\le\sqrt{7/3}=1.5275$ не
  исключены. Два хода: (i) перебор генуса соседями Кнезера над ℤ[ω]
  (mass formula ограничит объём); (ii) прямая минимизация $\rho$ по эрмитовым
  формам ранга 5 (25 вещественных параметров — CMA-задача, привычная проекту).
  Успех = $\chi(\R^{10})\le 7^5=16807$ против 59049. Лучший известный
  вещественный $\rho$ в 10D ≈ 1.63 ($\Lambda_{10}$) — до 1.5275 нужно 6%;
  шансы неочевидны, но пространство не тронуто.
- **Сканы подгрупп с жирным запасом**: $K_{12}/3K_{12}$ (порог d>1 при запасе
  22%) — вдруг индекс <3¹²; аналог для $\Lambda_9/3\Lambda_9$ с порогом
  $d\ge2/\sqrt3=1.1547$ — если найдётся подгруппа, произведение ℝ⁹×ℝ пробьёт
  3¹⁰ (нужен индекс <19683 при этой ширине). Оба скана — масштаб уже
  сделанного n=10-скана.
- **Продукт-калькулюс на лестницах** — оформить как ремарку в статье: лестницы
  ширин — это в точности «валюта» для оценок произведений
  ($1/w_1^2+1/w_2^2=1$), и 3ⁿ — неподвижная точка этого калькулюса; вот почему
  пробой требует либо ширины 1.1547 в 9D дешевле 19683, либо эйзенштейнова
  генуса.

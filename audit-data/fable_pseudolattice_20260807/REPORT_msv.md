rigorous / negative.

## Метод (новый для проекта)

`S = ⋃_{i=1..s}(P + t_i)`, разбиение — ячейки Вороного `S`; цвет ячейки узла
`t_i + g` — пара `(i, [g] ∈ P/Γ_i)`, `Γ_i ⊆ P` — своя подрешётка индекса `j_i`
на орбиту; `k = Σ j_i` цветов (любое k ≥ s, включая нечётные). Одноцветные
ячейки — трансляции одной ячейки: `d = min_i min_{γ∈Γ_i\0} dist(γ, V_i−V_i) /
max_i diam V_i`. При `s = 1` — решёточная схема Иванова дословно. Класс
подлинно не-решёточный; не совпадает ни с кластерным классом братской линии
(склейки ячеек одной решётки), ни с CMA-постановкой степенных мозаик §10
статьи (здесь косетная структура и точный HNF-перебор Γ_i в каждой оценке).

Сертификация: сепарации — опорные направления с точной опорой по всем
разностям вершин (никогда не завышены); диаметры — точные по вершинам;
d консервативно. Независимый верификатор — прямая генерация всех ячеек в
коробке 5³ периодов + SLSQP-дистанции (другой алгоритм); согласие на всех
финалистах ≤ 2·10⁻¹⁴. Калибровка: BCC/15 → 1.000000000, FCC/21 → √(7/6),
Q15 → 1.026555176 побитово = combigeo.

## Лемма чётной доминации (rigorous, внутри класса s = 2)

Для любой двухорбитной структуры центральная инверсия через `t/2` меняет
орбиты местами ⇒ ячейки орбит конгруэнтны и `K₁ = V₁−V₁ = K₂` **точно**.
Зазор цвета — `min(g_{j₁}, g_{j₂})`, где `g_j` = max по всем Γ индекса j от
`min_γ dist(γ, K)`; поэтому при любых (P,t)

    d(j₁, j₂) = min(g_{j₁}, g_{j₂})/Δ ≤ g_{j_min}/Δ = d(j_min, j_min),

т.е. **любое разбиение (j₁,j₂) доминируется симметричным (j,j) с j =
min(j₁,j₂) — с меньшим числом цветов**. Нечётный цвет в s=2-классе всегда
бесполезен; лестница s=2 по существу чётная (V_j := оптимум (j,j)).
Монотонности g_j по j нет: на ячейке чемпиона k=16 g₈ = 1.1353 > g₉ = 1.1200.

## Выводы

1. **k = 14 в ℝ³ закрыт и в МСВ-классе** (третий независимый класс после
   кластерного UNSAT и локальной жёсткости степенных мозаик): потолок s=2
   равен V₇ = 0.897 < 0.901 (решётка), s=3-разбиения ≤ 0.83. Мозаичная
   парадигма ниже 15 цветов не работает ни в одном исследованном расширении
   решёточного класса.
2. **Псевдо-решёточная свобода в ℝ³ не добавляет ширины, но добавляет
   ландшафт**: все оптимумы либо ниже решёточных, либо схлопываются в
   решётку; при этом путь «HCP-старт → мульти-орбитный NM → коллапс»
   выводит из локальных бассейнов Q-поиска (фронтир k=16 сдвинут). Это
   глобальное (по бассейнам) дополнение к локальному «без улучшения» §10.
3. Симметричные разбиения доминируют доказуемо (лемма), а дефицит МСВ
   максимален на нечётных k без симметричного разбиения.
4. Отрицательная заметка о модулированных ламинациях
   (NOTE_modulated_laminations.md): в однослоевом режиме периодическая
   модуляция профиля распадается на независимые копии линейной задачи —
   бюджет на CMA по профилям тратить не нужно.

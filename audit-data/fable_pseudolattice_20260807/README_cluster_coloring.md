## Метод

Новый для проекта класс псевдо-решётчатых раскрасок, строго обобщающий
решёточно-косетный. Мелкая решётка `L` задаёт мозаику ячеек Вороного; период
`G ⊆ L` индекса `N`; раскраска — **произвольное** G-периодическое отображение
`phi: L/G → {1..k}`, `k ≤ N`. Классы цвета могут быть невыпуклыми
объединениями ячеек («кластеры») — в отличие и от косетных раскрасок
(промежуточная `Γ`), и от силовых (Laguerre) разбиений другой сессии
(там один выпуклый многогранник на цвет за период).

Исчисление интервалов: ячейки центрально-симметричны ⇒ разностное тело
`V₀ − V₀ = 2V₀`, и расстояния между `V₀` и `V₀ + w` заполняют ровно отрезок
`[D(w), H(w)]`: `D(w) = 2·dist(w/2, V₀)` (лемма Иванова),
`H(w) = max_v |w + 2v|` по вершинам. Класс цвета реализует
`U(phi) = [0, diam V₀] ∪ ⋃ [D, H]` по одноцветным парам; качество —
наибольший мультипликативный зазор `(a, b)` в `U(phi)`:
`χ(ℝⁿ, [1, ℓ]) ≤ k` для всех `ℓ < b/a`. Для косетной раскраски это в точности
`d = D_min/diam`; пары с `H ≤ a` образуют кластер бесплатно.

Поиск: скан кластерного порога `a` по критическим значениям `H` × бинарный
поиск `b` по критическим значениям `D`; k-раскрашиваемость конфликтного графа
(ребро ⇔ интервал пары пересекает `(a, b)`) — DSATUR, затем CP-SAT (or-tools).
UNSAT — доказательство невозможности **на данном уровне** (L, G, cutoff,
сетка, eps); на весь класс не обобщается.

Гарантии честности:

- перечисление пар полное до `|w| ≤ cutoff`: редукция Бабая представителей
  классов + assert от потери пар (регрессия `test_windowing_regression_bcc42`;
  до фикса окно теряло дальние пары и давало фиктивные зазоры);
- зазоры заявляются только до `claim_cap = cutoff − diam`
  (вне окна `D(w) ≥ |w| − diam > claim_cap`);
- каждая найденная раскраска перепроверена двумя независимыми процедурами
  (GJK combigeo и SLSQP на H-представлении qhull; расхождения ≤ 2·10⁻¹⁴)
  и снабжена сертифицированной нижней границей `D` (опорный функционал по
  вершинам). Измеренные значения не оптимистичны.

## Результаты

Контроли (все воспроизведены точно): A₂/7 → √7/2 = 1.322876;
чемпион ℝ³ k=15 (Q-поиск) → 1.026555; FCC/21 → √(7/6) = 1.080123;
чемпион ℝ⁴ k=45 → 1.016339.

### ℝ³: жёсткость — кластерная свобода не добавляет ширины (негатив с механизмом)

| эксперимент | конфигурации | итог |
|---|---|---|
| `screen14` | champ14/champ15/BCC × периоды N=28..45, k=14 | **ни одного допустимого уровня**: обязательный конфликтный граф не 14-раскрашиваем при любом пороге кластера; все отказы — CP-SAT UNSAT (0 таймаутов) |
| `ladder` | k=15 (N=30,45), k=16 (N=32), k=17 (N=34) | ровно решёточные значения 1.026555 / 1.029720 / 1.064844 — улучшения нет |
| `inversions` | k=22←21, k=25←24, k=28←27, период ×2 | ровно тривиальный пол (значение базы); лишний цвет ширины не добавил |

**Механизм (новая величина — «цена склейки»).** Объединение любых двух ячеек
поднимает низ зазора с `diam` до `H_min = min_w H(w)`; измерено:
champ15 → 1.667, champ14 → 1.402, BCC → 1.673, FCC-класс → 1.482 (в единицах
diam). Чтобы склейка окупилась, нужна одноцветная сепарация `b ≥ H_min·r` при
меньшем числе цветов — то есть d ≈ 1.4 при k ≤ 14, тогда как вся решёточная
лестница до k=21 лежит ниже 1.263. На круглых ячейках кластеры доминированы —
вот почему все оптимумы поиска не используют ни одной склейки и совпадают с
решёточными. Следствие: кластерному классу нужны **плоские** ячейки
(`H_min/diam → 1`) — экран `screen14flat`.

### Статусы

- ℝ³, k=14, круглые ячейки: **negative result** (экран с доказанными UNSAT
  на уровнях; не доказательство для всего класса).
- ℝ³, k=15..17, 22, 25, 28: **measured** — совпадение с решёточной лестницей,
  улучшения нет (negative для кластерной свободы).
- Цена склейки: **измеренная величина** + структурное объяснение (idea → 
  подтверждена данными всех прогонов: ни один оптимум не склеивает).
- ℝ³ плоские ячейки (`screen14flat`, слоистые воксели s×s×h со сдвинутым
  стэкингом; s/h = 0.62/0.31 при N=54 и 0.55/0.275 при N=64): k=14 — снова
  **ни одного допустимого уровня**, все отказы UNSAT (0 таймаутов). Даже при
  почти бесплатной склейке воксельный класс на этих периодах не даёт зазора.
- ℝ⁴ (`probe4d`, период Γ₄₅×2, N=90): k=45 — ровно чемпионские 1.016339
  (верифицировано, расхождение 1.2·10⁻¹³); **k=44 — UNSAT на всех уровнях**
  (0 таймаутов, 5 с). Вывод ревю «45 — предел метода» распространяется с
  решёточно-косетного класса на кластерный при этом периоде.

### Итоговая классификация

Сильный отрицательный результат с механизмом: кластерная свобода
(невыпуклые классы, произвольные не-косетные разбиения) на круглых ячейках
доминирована ценой склейки и на 8 независимых конфигурациях k=14 (ℝ³) и k=44
(ℝ⁴) не даёт ни одного допустимого уровня — все отказы доказаны CP-SAT.
Подъячеечная программа ревю §6.1(a) в этой форме реализована и дала ответ:
пробой стены 45 (и 15 в ℝ³) требует не просто «цвет не постоянен на ячейке»,
а другой геометрии мелких тайлов; плоскоячеечный (воксельный) вариант на
малых периодах тоже закрыт.

Параметры всех прогонов, допуски, тайминги и среда — внутри JSON-артефактов;
поиск детерминирован (сидов нет), CP-SAT — 4 потока, таймаут на вызов
записан в `search_params`.

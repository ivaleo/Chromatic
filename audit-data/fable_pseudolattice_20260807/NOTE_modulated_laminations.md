# Отрицательный результат: периодическая модуляция профиля сдвигов ламинации не расширяет сертифицируемый класс в однослоевом режиме

Статус: **negative result** (строгий в рамках схемы сертификации (P1)+колонны;
вне этой схемы — структурный аргумент). Сессия fable_pseudolattice_20260807.

## Постановка

Ламинации проекта (ℝ⁹: 9604/7203, лестницы, башня 10–12) строят решётку
слоями `L × {i·t}` со сдвигом слоя `c_i = i·c` — **линейным** профилем
(это и делает объединение решёткой). Естественное псевдо-решётчатое обобщение:
произвольный периодический профиль `{c_i}`, период `p` (объединение перестаёт
быть решёткой, но остаётся периодическим множеством; цвет слоя — `i mod m`,
горизонтальный цвет — как раньше). Свободных параметров становится `p·n`
вместо `n`; вопрос — расширяет ли это допустимую область, в частности, снимает
ли несовместимость `m = 3` в ℝ⁹ (слоям нужно `t ≳ 1.15`, строгому диаметру —
`t ≤ 1`).

## Ответ: нет — в однослоевом режиме модуляция распадается на независимые копии линейной задачи

Два факта переносятся на произвольный профиль дословно:

- **(P1) не зависит от профиля.** Для точки `(x, z)` берём ближайший слой:
  `dist² ≤ R(L)² + t²/4`, значит `diam ≤ √(diam(L)² + t²)` при **любых** `c_i`
  (в RESULTS это уже отмечено для лестницы 9604: «diam ≤ √(6+t²) верно при
  любом сдвиге»).
- **(Колонна/P2).** Истинная ячейка точки слоя `i` содержится в ячейке
  относительно только своего слоя, т.е. в колонне `V₀(L) × ℝ`; поэтому
  горизонтальные разделения ≥ `D_L(v)` — тоже при любом профиле.

Одноцветные пары слоёв — это `j − i ≡ 0 (mod m)`. **Однослоевой режим**: все
пары с `|j − i| ≥ 2m` закрыты автоматически (высота `2mt ≥ 2·diam`); во всех
конструкциях проекта это выполнено, потому что `m·t` подбирается впритык к
порогу (`m=3: 3t ≈ 3.45`, `m=4: 4t ≈ 3.72`, лестницы `m·t ≈ 3.2–3.3` при
`2·diam ≈ 5.2`). Остаются только пары `(i, i+m)`, и сертифицируемое условие
для каждой пары зависит от профиля **только через** `δ_i = c_{i+m} − c_i`
(вертикаль фиксирована `= m·t`, горизонтальные классы — один и тот же слой
кода склейки). Значит система условий распадается в `p` независимых копий
одной и той же задачи «найти δ, выталкивающий все классы слоя», а линейный
профиль реализует любое её решение (`δ = m·c`, `c` свободен). Оптимум по
профилям равен оптимуму линейной ламинации; новых конструкций нет.

## Границы применимости аргумента

1. Аргумент строг в рамках схемы сертификации проекта ((P1) + колонны +
   явные слоевые классы): всё, что она способна доказать для модулированного
   профиля, она уже доказывает для линейного.
2. Вне схемы точные ячейки зависят от соседних сдвигов (`c_{i±1}`), то есть
   формально модуляция меняет разбиение. Но выигрыш мог бы прийти только через
   **точный** диаметр/радиус покрытия немодулированной ячейки — ровно тот
   объект, отсутствие сертификата для которого и есть узкое место 7203
   (REVIEW-2026-08-07 §5). Модуляция не обходит его, а усугубляет (ячейки
   теряют решёточную однородность).
3. Двухслоевой режим (`2m·t < 2·diam`, релевантны `Δ = m` и `2m`) линейным
   профилем связан (`δ` и `2δ`), а модулированным — развязан; там аргумент не
   работает. Но этот режим требует `m·t < diam`, т.е. слоёв вдвое чаще порога —
   в конструкциях проекта он не встречается (см. выше), а войти в него
   означает заведомо провалить слоевые условия ещё на уровне `Δ = m`.

## Следствие для плана поиска

Не тратить бюджет на CMA по модулированным профилям в архитектуре ламинаций
ℝ⁹–ℝ¹²: пространство поиска эффективно не расширяется. Псевдо-решётчатые
степени свободы надо вкладывать не в вертикальный профиль, а в **горизонтальную
структуру слоя** (мульти-узловые орбиты — см. msv_core.py) или в сертификат
радиуса покрытия (REVIEW §5).

## Метод: пер-орбитные косетные раскраски мульти-решёток (МСВ)

Периодическое множество `S = ⋃_{i=1..s} (P + t_i)` (решётка периодов `P`,
`s` орбит узлов), разбиение — ячейки Вороного `S`. Каждой орбите — своя
подрешётка `Γ_i ⊆ P` индекса `j_i`; цвет ячейки узла `t_i + g` — пара
`(i, [g] ∈ P/Γ_i)`. Всего `k = Σ j_i` цветов (любое `k ≥ s`, включая нечётные —
в отличие от схемы «одна Γ на всех», дающей только `k = s·j`).

Одноцветные ячейки лежат в одной орбите ⇒ это трансляции одной ячейки `V_i`, и

    gap_i = min_{γ ∈ Γ_i \ 0} dist(γ, V_i − V_i),
    d     = min_i gap_i / max_i diam V_i,          d ≥ 1 ⇒ χ(ℝⁿ,[1,d]) ≤ k.

При `s = 1` — в точности решёточная схема Иванова (`dist(γ, V₀−V₀) = D(γ)`).
Класс строго шире решёточного (ср. REVIEW-2026-08-07 §6.1(b)); относительно
силовых разбиений параллельной сессии — срез `w = 0` с косетной структурой
цветов и структурным (не CMA) поиском: HNF-перебор `Γ_i` точен внутри каждой
оценки.

## Сертификация (статус «measured, сертифицированная сепарация»)

- ячейка строится как пересечение полупространств всех соседей в радиусе,
  с гарантией `R_cut ≥ 2·max|vertex|` (иначе радиус наращивается) — политоп
  точен с точностью qhull;
- `dist(γ, K)` сертифицируется **опорным направлением**: `lb = ⟨u,γ⟩ − h_K(u)`,
  где `h_K` считается по ПОЛНОМУ множеству разностей вершин; направление
  берётся из Франка–Вульфа (валидно при любой сходимости);
- диаметр — точный максимум по парам вершин (надмножество ячейки ⇒ не занижен);
- итоговое `d` **консервативно** (занижено, не завышено) с точностью до
  float-округления. Рационализация уровня [С] — отдельный шаг, не здесь.

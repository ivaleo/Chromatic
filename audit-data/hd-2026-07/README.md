# Исследование больших размерностей (n ≥ 5) — сессия 2026‑07‑23

Скрипты и данные экспериментов, стоящих за разделами §sec:big, §sec:extra,
§sec:stair и §sec:open статьи `paper/chi4-45.tex`. Все результаты, не снабжённые
точным сертификатом, — **вычислительные наблюдения** (в статье помечены как
«вычислительное свидетельство»); здесь фиксируется, что именно и как проверялось.

**Запуск.** Из этой папки, с виртуальным окружением проекта
(`source ../../.venv/bin/activate`) и установленным модулем `combigeo`
(`pip install ../../combigeo`). Скрипты добавляют в `sys.path` эту папку и
`../` (== `audit-data`, откуда берутся `general_csp.py`, `cyclic_csp.py`).

## Инфраструктура
| Скрипт | Назначение |
|---|---|
| `lattices.py` | Стандартные решётки Aₙ*, Dₙ, Dₙ*, Eₙ, Eₙ* как базисы (norm det = 1); проверка diam через `combigeo.voronoi_cell`. |
| `covrad.py` | **Безвершинный радиус покрытия** R (⇒ diam = 2R): максимум ‖x‖ по ячейке серией LP по опорным полупространствам. Совпал со всеми известными замкнутыми формами до ℝ⁹ (Aₙ*=√((n+2)/3), Dₙ=√(n/2), E₆*/E₈=√2, E₇=√3). |

## Классические χ(ℝ⁵), χ(ℝ⁶) — воспроизведение и попытки улучшить
| Скрипт | Результат |
|---|---|
| `campaign_hd.py`, `campaign_flat.py` | Кампании поиска минимального индекса по решёткам dim 5–9 (C++ `min_conflicts`). Подтвердили χ(ℝ⁵)≤140 (A₅*), χ(ℝ⁶)≤343 (E₆*) как минимальные среди опробованных индексов. **Калибровка:** надёжный бюджет min‑conflicts — 2000 шагов × 15 рестартов (1000×4 даёт ложные негативы). |
| `feas_k.py` | Карта пригодных индексов A₅* при ℓ=1: 140,144,156,160,164,166,168,172,…, далее плотно с 183. Ниже 140 — пусто. |

## Размерность 7: E₇*/1372 (§sec:big, §sec:open)
| Скрипт | Результат |
|---|---|
| `e7_abpr.py` | **Точная реконструкция** конструкции АБПР (матрицы M, C₇ из arXiv:2112.13438v2): \|F₁\|=24284, \|det C₇\|=1372, Λ′∩F=∅ — подтверждено. Отношение покрытие/упаковка E₇* = √(7/3). |
| `densify_e7.py` | C₇ **неуплотняема**: нет валидной надрешётки индекса 686/196 (перебор всех склеивающих векторов порядка 2 и 7 — 0 пригодных). Строгая проверка конечного множества. |
| `beat_e7.py`, `sa_e7.py`, `rand_e7.py` | Градиентный спуск / отжиг / 2·10⁶ случайных базисов из коротких незапрещённых векторов — ни одна пригодная подрешётка индекса <1372 (случайные пригодные встречаются лишь при индексе ≥2052). **Важный баг (учтён):** `forbidden_coords` хранит один из пары ±v ⇒ фильтровать пул надо по обоим. |
| `clique_e7.py` | Клика графа конфликтов (жадно): 80 (A₅*), 541 (E₇*) — меньше индекса. |

## «Вне схемы АБПР»: клеточные раскраски (§sec:big, §sec:open)
| Скрипт | Результат |
|---|---|
| `conflict_graph.py` | При Γ=Λ′ множество F покрывает **все** ненулевые классы Λ/Λ′ (A₅*/140 и E₇*/1372) ⇒ граф конфликтов полон K_index. Также: множество конфликтов **точно** совпадает с F (у всех v∈F макс. расстояние между ячейками D′(v)≥2R). |
| `conflict_color.py`, `cpsat_color.py` | Раскраска графа конфликтов на измельчённых периодах (DSATUR / CP‑SAT). Для A₅* при периоде индекса 280 равенство χ=140 **доказано** SAT‑решателем (139 цветов — UNSAT). Вывод: клеточные раскраски (в проверенных случаях) не бьют решёточную оценку. |

## Структурные попытки (дали субоптимум — тупики, зафиксированы)
| Скрипт | Результат |
|---|---|
| `symlat.py`, `invariant_search.py`, `pool_cover.py`, `gorbit_search.py` | Поиск раскрасок, инвариантных относительно координатного автоморфизма Aₙ* (собственные векторы / орбиты). Даёт лишь субоптимум (ℝ⁵: индексы 243/1519 вместо 140) — **оптимальные раскраски не инвариантны** относительно координатного цикла. |
| `lazy_solve.py` | Ленивая генерация ограничений (CEGAR): не сходится для жёстких идеальных решений (E₆*/343 не собрал). |
| `cpsat_solve.py` | Точный CP‑SAT для модулярно‑линейного CSP: таймаут даже на A₅*/140 — общие SAT/CP не тянут модулярную структуру. |
| `bench_mc.py` | Бенчмарк C++ vs Python `min_conflicts`. |

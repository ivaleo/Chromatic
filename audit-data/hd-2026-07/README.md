# Исследование больших размерностей (n ≥ 5) — сессия 2026‑07‑23…29

Скрипты и данные экспериментов, стоящих за разделами §sec:big, §sec:extra,
§sec:stair и §sec:open статьи `paper/chi4-45.tex`. Все результаты, не снабжённые
точным сертификатом, — **вычислительные наблюдения** (в статье помечены как
«вычислительное свидетельство»); здесь фиксируется, что именно и как проверялось.

**Запуск.** Из этой папки, с виртуальным окружением проекта
(`source ../../.venv/bin/activate`) и установленным модулем `combigeo`
(`pip install ../../combigeo`). Скрипты добавляют в `sys.path` эту папку и
`../` (== `audit-data`, откуда берутся `general_csp.py`, `cyclic_csp.py`).

## Новый сертифицированный результат: χ(ℝ⁷) ≤ 1323

Получена решёточная раскраска общего положения, улучшающая оценку АБПР
`1372`:

\[
\boxed{\chi(\mathbb R^7)\le1323},\qquad
\chi(\mathbb R^7,[1,\ell])\le1323\quad(\ell\le1.007).
\]

Родительская решётка задаётся рациональной Gram-матрицей
`Q = Q_integer / 10000`, подрешётка имеет точный индекс `1323` и фактор
`Z/3 × Z/21 × Z/21`. Для рационализованной конструкции:

- `det C = |im φ| = 1323`, Smith-диагональ `[1,1,1,1,3,21,21]`;
- ячейка Вороного имеет 254 фасеты и 39 296 вершин;
- все 39 296 вершин пересчитаны в точной рациональной арифметике;
- полный список векторов подрешётки, способных нарушить условие, содержит 70
  ненулевых векторов и совпадает у точного перебора коэффициентного куба и
  независимого C++-перечислителя;
- для каждого из 70 векторов проверены точные условия ККТ проекции;
- `D_min² − diam² = 0.048395385576… > 0`, а
  `D_min / diam = 1.007032309006…`;
- независимое построение запрещённого множества даёт `|F|=21193` и
  `ker φ ∩ F = ∅`.

| Файл | Роль |
|---|---|
| `prime_radon.py` | Новый первичный поиск: все проективные линейные формы над Fₚ оцениваются одним конечным преобразованием Радона, вычисленным n-мерным FFT; поддержаны точные ядра, HNF/SNF, парные ходы и точный перебор полевых подпространств. |
| `prime_campaign.py`, `prime_screen_e7.json` | Калибровка: независимо восстанавливает 140, 343 и 1372; исходный экран индексов ниже 1372. |
| `prime_weighted_campaign.py`, `prime_weighted_e7.json` | Геометрически взвешенный Radon-поиск с весом `exp(β(1−D/diam))`; нашёл ядро индекса 1323 с шестью пограничными конфликтами `D/diam=0.886405…` вместо глубокого конфликта обычного count-поиска. |
| `metric_deform.py`, `metric_deform_e7_1323.json` | CMA-ES по симметрическим деформациям нулевого следа `B=B₀ exp(H)` при фиксированном ядре. Радиус покрытия в каждой оценке вычисляется по **всем** вершинам dual-Qhull, а не случайной нижней оценкой. За 520 оценок достигнуто `D/diam=1.006963…`. |
| `verify_metric_candidate.py`, `metric_deform_e7_1323_certificate.json` | Рационализация со знаменателем 10⁴ и итоговый точный аудит вершин, коротких векторов и KKT-проекций. Это опорный сертификат оценки 1323. |

Воспроизведение итогового сертификата из корня репозитория:

```bash
.venv/bin/python -u audit-data/hd-2026-07/verify_metric_candidate.py \
  audit-data/hd-2026-07/metric_deform_e7_1323.json \
  --denominator 10000 \
  --output audit-data/hd-2026-07/metric_deform_e7_1323_certificate.json
```

## Экраны ℝ⁸ и ℝ⁹: нового рекорда не получено

После результата `1323` тот же подход и два новых ленивых варианта были
проверены на ближайших индексах ниже известных оценок
`χ(ℝ⁸)≤2401` и `χ(ℝ⁹)≤17253`. Это **отрицательные вычислительные экраны**, а
не доказательства невозможности: ни один найденный кандидат не достиг
необходимого порога `D/diam ≥ 1`.

| Размерность / цель | Экран и воспроизводимый итог |
|---|---|
| ℝ⁸, индекс 2400 | На точном `E₈` построено `|F|=93240`. Для структур `[4,4,2,3,5,5]`, `[4,2,2,2,3,5,5]`, `[2,2,2,2,2,3,5,5]` обычный Radon-поиск оставил соответственно 9, 11, 11 конфликтов (`prime_screen_e8_2400.json`). Геометрические веса дали минимум `0.707106…`; деформация подняла его лишь до `0.764250…` за четыре дорогих поколения (`prime_weighted_e8_2400.json`, `metric_deform_e8_2400.json`). |
| ℝ⁸, соседи точного `E₈/2401` | Восстановлена точная матрица умножения на `3+ω` (исходный запас `1.080123…`). Среди `10⁶` разреженных целочисленных возмущений найдено 722 различных точных матрицы с `|det|=2400`; лучший минимум равен `0.707106…` (`e8_neighbor_search.py`, `e8_neighbor_2400.json`). |
| ℝ⁹, индекс 16875 | Точечный ленивый CEGAR: 250 раундов, core 5896, лучший минимум `0.700649…` (`lazy_prime_a9_16875.json`). Новый `S₁₀`-orbit-CEGAR за 40 раундов расширил core до 165901 и поднял лучший минимум до `0.81649658…`, после чего Radon-оракул оставлял один конфликт на core (`a9_orbit_16875.json`). |
| ℝ⁹, индекс 17150 | Ближайшее малопростое число `17150=2·5²·7³` (на 103 ниже 17253). Много-кандидатный точечный CEGAR дал `0.687551…`; орбитальный вариант дошёл до `0.81649658…`, core 163546, 37 раундов (`lazy_cxx_a9_17150.json`, `a9_orbit_17150.json`). |
| ℝ⁹, индексы 17010 и 16384 | Направленное сохранение пяти `F₃`-характеров матрицы `C₉` и замена фактора `71→70` дало лишь `0.627645…` (`a9_replace71_17010.json`). Для структуры `[4]⁷`, индекс 16384, лучший минимум `0.696310…` (`lazy_prime_a9_16384.json`). |

Полное запрещённое множество `A₉*` не материализуется: попытка превысила
пятиминутный лимит. Вместо этого `lazy_prime_campaign.py` использует полный
разделяющий оракул для конкретной подрешётки. Он перечисляет только её векторы
с `|v|<2 diam`; полнота следует из
`dist(V,v+V) ≥ |v|−diam`. На контрольном кандидате `E₈` оракул за `0.07` с
в точности восстановил восемь конфликтов полного множества из 93240 точек.

`a9_orbit_cegar.py` усиливает один контрпример всей его точной орбитой под
`S₁₀`. Поэтому 40 геометрических вызовов заменяют тысячи точечных итераций.
Статус `heuristic_core_failure` означает только, что заданный бюджет
Radon/min-conflicts не решил накопленный core; это не UNSAT-сертификат.

Следующий предлагаемый механизм совместного поиска описан отдельно:
[`NEXT_MECHANISM.md`](NEXT_MECHANISM.md).

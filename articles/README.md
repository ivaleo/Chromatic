# articles/ — источники и методологическая основа

Здесь перечислены работы, на которых стоит проект (методология, оценки-ориентиры,
контекст «сверху-снизу»). **Сами PDF в репозиторий не включены** — это
опубликованные работы третьих лиц, распространение которых ограничено авторским
правом издателей. Ниже — библиография со ссылками; файлы легко находятся по
названию / DOI / arXiv.

Единственный включённый в каталог файл — исходник `Qpoisk.c` (см. в конце).

## Методологическая основа

- **Л. Л. Иванов.** О хроматических числах ℝ² и ℝ³ с интервалами запрещённых
  расстояний // Вестник РУДН, сер. Математика. Информатика. Физика. — 2011. —
  № 1. — С. 14–29.
  Методологический фундамент проекта: лемма о середине, нормировка `d`, таблицы
  для ℝ² и ℝ³. Обе таблицы воспроизведены полностью (7/7 и 5/5 строк); попутно
  найдены и исправлены три опечатки в матрицах подрешёток.

- **Л. Л. Иванов.** Кандидатская диссертация. — РУДН, 2011.
  Расширенный первоисточник той же методологии (гл. 2 = статья выше + χ(ℝ⁴) ≥ 7;
  гл. 3 — проблема Борсука).

- **A. Arman, A. Bondarenko, A. Prymak, D. Radchenko.** Upper bounds on the
  chromatic number of Eⁿ in low dimensions. — **arXiv:2112.13438**.
  **Ключевая для проекта**: источник оценок 49 / 140 / 343 / 1372 / 2401 / 17253.
  Наши расчёты впервые дали точные интервальные константы их конструкций и
  вычислительное свидетельство в пользу их гипотезы OQ1 о минимальности 49.

## Хроматические числа графов Вороного (смежная, не метрическая постановка)

- **M. Dutour Sikirić, D. A. Madore, P. Moustrou, F. Vallentin.** Coloring the
  Voronoi tessellation of lattices // J. London Math. Soc. 104 (2021).
  Хроматические числа графов Вороного решёток (инвариант касания ячеек, не
  метрический): χ(ℤⁿ)=2, χ(Aₙ)=χ(Aₙ*)=n+1, χ(Dₙ*)=4, χ(E₈)=16, χ(Λ₂₄)=4096.
  Полезный контраст к метрической задаче проекта.

- **F. Vallentin, M. Weißbach, F. Zimmermann.** The chromatic number of
  4-dimensional lattices. — **arXiv:2407.03513**.
  16 комбинаторных классов графов Вороного 4-мерных решёток, χ ∈ {2,…,7}, у D₄
  χ=4. Их формы дали 16 решёток-представителей для нашего 4D-скана k = 2..54.

## Нижние оценки и асимптотический контекст

- **Д. Д. Черкашин, А. М. Райгородский.** О хроматических числах пространств
  малой размерности // Доклады Академии наук, 2017.
  Нижние границы малых размерностей — контекст «сверху-снизу» для наших верхних
  оценок.

- **Е. И. Горская, И. М. Митричева (Шитова), В. Ю. Протасов, А. М. Райгородский.**
  Оценки хроматических чисел евклидова пространства методами выпуклой
  минимизации // Математический сборник, 2009.
  Асимптотические нижние оценки ζₖ именно для интервальной постановки:
  χ(ℝⁿ, [1, √k]) ≥ (ζₖ + o(1))ⁿ.

- **A. D. N. J. de Grey.** The chromatic number of the plane is at least 5. —
  **arXiv:1804.02385** (2018).
  Нижняя граница χ(ℝ²) ≥ 5 — рамка, в которой живёт верхняя оценка 7 (A₂, k=7).

- **R. Prosanov.** A new proof of the Larman–Rogers upper bound for the chromatic
  number of the Euclidean space // Discrete Applied Mathematics 276 (2020).
  Контекст асимптотической верхней оценки (3+o(1))ⁿ (Ларман–Роджерс).

- **А. И. Гарбер, А. Н. Магазинов.** Обзор по гипотезе Вороного о параллелоэдрах
  // Успехи математических наук 77:1 (2022).
  Обосновывает охват метода: решёточные ячейки Вороного аффинно исчерпывают
  параллелоэдры во всех размерностях проекта, кроме n=6 (там гипотеза открыта).

## Включённый исходник

- **`Qpoisk.c`** — эталонный C-исходник глобального безградиентного оптимизатора
  А. Горнова (Q-поиск: случайная проба в текущем брусе, сжатие бруса,
  периодический сброс к полному домену → глобальность). Портирован в
  `audit-data/qsearch.py` (одиночный инстанс) и `audit-data/q_frontier.py`
  (ансамбль). Приведён здесь как первоисточник алгоритма для верификации порта.

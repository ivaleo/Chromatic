## Методологическая основа проекта

### Иванов R2 R3.pdf
- **Работа:** Л.Л. Иванов. «О хроматических числах ℝ² и ℝ³ с интервалами
  запрещённых расстояний» // Вестник РУДН, сер. Математика. Информатика.
  Физика. — 2011. — № 1. — С. 14–29.
- **Значимость:** методологический фундамент всего воркспейса (лемма о середине,
  нормировка d, таблицы для ℝ² и ℝ³). Обе таблицы воспроизведены полностью
  (7/7 и 5/5 строк); попутно найдены и исправлены три опечатки в матрицах
  подрешёток (AUDIT §2.2).

### Диссертация - Иванов.pdf
- **Работа:** Л.Л. Иванов. Кандидатская диссертация, РУДН, 2011
  (гл. 2 = статья выше + χ(ℝ⁴) ≥ 7; гл. 3 — проблема Борсука).
- **Значимость:** расширенный первоисточник той же методологии; использована
  при сверке таблиц и матриц (опечатки статьи повторены и в диссертации).

### 2112.13438v2.pdf
- **Работа:** A. Arman, A. Bondarenko, A. Prymak, D. Radchenko. «Upper bounds
  on chromatic number of Eⁿ in low dimensions», arXiv:2112.13438.
- **Значимость:** **ключевая для проекта** — источники оценок 49/140/343/1372/
  2401/17253; наши расчёты впервые дали точные интервальные константы их
  конструкций (AUDIT §2.3а) и вычислительное свидетельство в пользу их
  гипотезы OQ1 о минимальности 49 (AUDIT §2.3в).

## Хроматические числа графов Вороного (смежная, не метрическая постановка)

### Journal_of_London_Math_Soc_2021_Dutour_Sikirić_Coloring_the_Voronoi.pdf
- **Работа:** M. Dutour Sikirić, D.A. Madore, P. Moustrou, F. Vallentin.
  «Coloring the Voronoi tessellation of lattices» // J. London Math. Soc. 104
  (2021).
- **Значимость:** хроматические числа графов Вороного решёток (инвариант
  касания ячеек, не метрический): χ(ℤⁿ)=2, χ(Aₙ)=χ(Aₙ*)=n+1, χ(Dₙ*)=4,
  χ(E₈)=16, χ(Λ₂₄)=4096. Полезный контраст к метрической задаче проекта;
  добавлена в библиографию `voronoi/docs/article.tex`.

### THE CHROMATIC NUMBER OF 4-DIMENSIONAL LATTICES 2024.pdf
- **Работа:** F. Vallentin, M. Weißbach, F. Zimmermann. «The chromatic number
  of 4-dimensional lattices», arXiv:2407.03513 — **версия v1**.
- **Значимость:** 16 комбинаторных классов графов Вороного 4-мерных решёток,
  χ ∈ {2,…,7}, у D₄ χ=4; их формы дали 16 решёток-представителей для нашего
  4D-скана k = 2..54 (AUDIT §2.3в).
- **Дубликат:** та же статья, что «ХЧ 4.pdf» (там v3).

### ХЧ 4.pdf
- **Работа:** та же статья Vallentin–Weißbach–Zimmermann, arXiv:2407.03513 —
  **версия v3** (дубликат по содержанию файла выше).
- **Значимость:** см. выше; при работе достаточно одного из двух файлов
  (актуальнее v3).

## Нижние оценки и контекст

### ХЧ пространств.pdf
- **Работа:** Д.Д. Черкашин, А.М. Райгородский. «О хроматических числах
  пространств малой размерности» // ДАН, 2017 (нижние оценки).
- **Значимость:** нижние границы малых размерностей — контекст «сверху-снизу»
  для наших верхних оценок (AUDIT §2.3д).
- **Дубликат:** ≡ «elibrary_28107270_82384469.pdf» **побайтово**.

### elibrary_28107270_82384469.pdf
- **Работа:** побайтовая копия «ХЧ пространств.pdf» (Черкашин–Райгородский,
  ДАН 2017) — выгрузка с eLibrary.
- **Значимость:** дубликат; самостоятельной ценности не несёт.

### otsenka_khromaticheskikh_chisel_evklidova_prostranstva_539clir2l1.pdf
- **Работа:** Е.И. Горская, И.М. Митричева (Шитова), В.Ю. Протасов,
  А.М. Райгородский. «Оценки хроматических чисел евклидова пространства
  методами выпуклой минимизации» // Матем. сб., 2009.
- **Значимость:** асимптотические нижние оценки ζ_k — нижний контекст именно
  для интервальной постановки: χ(ℝⁿ, [1, √k]) ≥ (ζ_k + o(1))ⁿ.

### 2018 хр число плоскости 5.pdf
- **Работа:** A.D.N.J. de Grey. «The chromatic number of the plane is at
  least 5», 2018 (arXiv:1804.02385).
- **Значимость:** нижняя граница χ(ℝ²) ≥ 5 из введения `article.tex` — рамка,
  в которой живёт верхняя оценка 7 (A₂, k=7).

### 1-s2.0-S0166218X19304172-main.pdf
- **Работа:** R. Prosanov. «A new proof of the Larman–Rogers upper bound for
  the chromatic number of the Euclidean space» // Discrete Applied
  Mathematics 276 (2020).
- **Значимость:** контекст асимптотической верхней оценки (3+o(1))ⁿ
  (Ларман–Роджерс), на фоне которой работают решёточные конструкции малых
  размерностей.

### гипотеза вороного.pdf
- **Работа:** А.И. Гарбер, А.Н. Магазинов. Обзор по гипотезе Вороного о
  параллелоэдрах // УМН 77:1 (2022); гипотеза доказана при d ≤ 5.
- **Значимость:** обосновывает охват метода — решёточные ячейки Вороного
  аффинно исчерпывают параллелоэдры во всех размерностях проекта, кроме n=6
  (там гипотеза открыта).

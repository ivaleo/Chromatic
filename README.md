# Chromatic — новые верхние оценки хроматических чисел евклидовых пространств

χ(ℝ⁴) ≤ 45, χ(ℝ⁵) ≤ 132, χ(ℝ⁷) ≤ 1029, χ(ℝ⁹) ≤ 7203, χ(ℝ¹⁰) ≤ 45619
и точные ширины запрещённых интервалов до ℝ¹² и ℝ²⁴

Набор из трёх взаимосвязанных проектов для исследования верхних оценок
хроматического числа евклидова пространства с запрещённым интервалом
расстояний (методология Л.Л. Иванова): пространство раскрашивается периодически
по подрешётке Γ ⊂ Λ, число цветов k = [Λ:Γ] = |det(M)|, а корректность
раскраски определяется нормированным запрещённым расстоянием d = D/diam(V₀) ≥ 1.

```
Chromatic/
├── voronoi/     — python-пакет voronoi4d (эталонная реализация, размерность 4)
├── combigeo/    — C++ ядро + python-модуль (pybind11), размерности 2…6
└── chromatic/   — над-проект: единый фасад над обоими бэкендами
```

## Статья и результаты

Основной итог исследования — статья **[`paper/chi4-45.tex`](paper/chi4-45.tex)**
(собирается в `paper/chi4-45.pdf`, `figures.py` строит иллюстрации):

- **χ(ℝ⁴) ≤ 45** (было 49) — раскраска решёткой общего положения, ключевое
  неравенство доказано в точной рациональной арифметике; плюс раскраска в 48
  цветов для более широкого интервала.
- **χ(ℝ⁵) ≤ 132** (было 140) — пороговое расширение портфеля дискретных
  бассейнов, блочный поиск при индексах 133/132 и непрерывная деформация
  метрики. Рациональный сертификат проверяет все 720 вершин ячейки Вороного,
  все 36 потенциально опасных векторов и даёт
  `D/diam = 1.010897714…`, то есть также
  `χ(ℝ⁵,[1,1.01]) ≤ 132`. Отдельный полностью точный аудит заново строит
  62 фасеты и полный граф из 720 вершин/1800 рёбер без Qhull.
- **χ(ℝ⁷) ≤ 1323** (было 1372) — первичный Radon/FFT-поиск ядра
  `Z/3 × Z/21 × Z/21`, затем непрерывная деформация Gram-формы. Рациональный
  сертификат проверяет все 39 296 вершин ячейки Вороного и все 70 потенциально
  опасных векторов; нормированная ширина `d = 1.007032309…`.
- **χ(ℝ⁷) ≤ 1029, χ(ℝ⁹) ≤ 7203, ширины 9604 → 1.058 и 3¹² → 1.2247
  (кампания 07.08.2026)** — три рычага: (1) **планарная теорема**
  `D((3+ω)Λ) ≥ √(7/3)·λ₁` для всех эйзенштейновых решёток (проекция на
  плоскость минимального вектора; закрывает половину открытого вопроса о
  тождестве и делает строгой ширину `χ(ℝ²⁴,[1,√(7/6))) ≤ 7¹²`);
  (2) **кусочный сертификат диаметра** слоёной решётки — общее измельчение
  двух сдвинутых разбиений Вороного, на кусках максимум по высоте — выпуклая
  квадратика, максимум в вершинах: диаметр вычисляется, а не оценивается
  (калибровка на точно известном 12005 сходится с точностью зазора 10⁻⁶);
  (3) ламинирование `E₆*/343` — порог «m ≥ 4» был артефактом дыр E₈, у E₆*
  слои проходят при `m = 3`, индекс `3·343 = 1029 < 1323`. Сертификат решил
  и судьбу кандидата 7203 (`diam = 2.602571 < √7`), и ширину 9604 (1.058127).
  В ℝ¹² правило `d = 2/ρ` на Коксетере–Тодде даёт ширину `√(3/2) = 1.224745`
  при том же индексе 3¹². Плюс инрадиусная лемма `D(v) ≤ |v| − λ₁`: при
  `ρ < 2` подгруппы строго между 3Λ и Λ невозможны — прежний скан n=10
  стал следствием. Статусы и данные: RESULTS.md.
- **χ(ℝ¹⁰) ≤ 45619** (было 3¹⁰ = 59049) — **продуктовое исчисление ширин**.
  Для ортогональной суммы ячейка есть произведение ячеек, поэтому
  `diam² = Σ diamᵢ²`, а `D(v)² = Σ Dᵢ(vᵢ)²` — минимум на одном ненулевом блоке.
  Исключение масштабов блоков сворачивает допустимость в одно неравенство по
  ширинам: **`Σ 1/dᵢ² ≤ 1`, причём `ℓ = (Σ 1/dᵢ²)^(−1/2)`** (прежнее `Σρᵢ² ≤ 4` —
  частный случай при `Γᵢ = 3Λᵢ`). Ширина — не отчёт о качестве, а расходуемый
  ресурс, и блоки можно брать **разного индекса**: `E₈/2401` тратит `6/7`,
  плоский проставок `aA₂/(5+2ω)aA₂` индекса 19 — `4/31`, сумма `214/217 < 1`.
  Отсюда `χ(ℝ¹⁰,[1,√(217/214)]) ≤ 2401·19 = 45619`; проверено сквозным
  построением решётки. Индекс 19 в плоскости **неулучшаем**: полный перебор форм
  Эрмита и форм решёток даёт порог `d ≥ √7` впервые при k=19 (16/17/18 → 2.598/
  2.520/2.479), а `k ≤ 16` запрещён доказательно — объёмный экран Минковского
  плюс новый инрадиусный `k ≥ (ℓ·diam+λ₁)ⁿ/(γₙ^(n/2)·det Λ)`, минимум по формам
  от максимума двух равен 16.021. Динамика по разбиениям
  размерности воспроизводит все рекорды проекта (4:45, 5:132, 6:343, 7:1029,
  8:2401, 9:7203, 12:3¹², 24:7¹²) и добавляет `n=25: 4·7¹²` и `n=26: 19·7¹²`
  (в 15.3 и 9.7 раза лучше 3ⁿ). Плюс **теорема о бюджете слоя**:
  `R_L ≤ (diam₀/2)·√(d₀²−1)` — избыток ширины базы есть в точности бюджет
  радиуса покрытия на дополнительные измерения; для `E₈/2401` он равен `1/2`, и
  9604 (прямая) и 45619 (шестиугольник) — два способа потратить один бюджет.
  Отрицательное: `D_min((3+ω)K₁₂)` равно ровно планарному полу `√(7/3)λ₁`, так что
  `7⁶` в ℝ¹² невозможно. Статусы и данные: RESULTS.md.
- **χ(ℝ⁹) ≤ 9604** (было 17253) — не поиск ядра с нуля, а **ламинирование**:
  девятое измерение надстраивается слоями над эйзенштейновой раскраской
  `E₈/2401`. Слои идут с шагом `t` и сдвигом `c`, характер `(3+ω)` поднимается
  склейкой `a ∈ 𝔽₇⁴` и модулем слоя `m`, индекс равен `2401·m`. Точная форма —
  `χ(ℝ⁹,[1,1.0097]) ≤ 9604` при `t = 0.93`. Два ключевых неравенства
  доказываются в одну строку: `diam ≤ √(diam(E₈)² + t²)` (берём ближайший слой)
  и `D(v) ≥ D_{E₈}(v)` для горизонтальных `v` (так как `V₀(Λ) ⊆ V₀(E₈)×ℝ`),
  поэтому запас `d(E₈/2401) = √(7/6)` — это в точности бюджет на рост ячейки, а
  численно проверять надо лишь слоевые векторы; их единицы. Сдвиг `c` — главный
  рычаг: смещение с орбит глубоких дыр разрушает «дважды глубокую дыру» и
  опускает настоящий диаметр ниже границы. Отсюда же **лестница ширин в ℝ⁹**
  (её у проекта не было): `9604 → 1.0098`, `12005 → 1.0397`, `14406 → 1.0539`,
  `16807 → 1.0623`, `19208 → 1.0667`, `24010 → 1.0705`, `28812 → 1.0736`, с
  пределом `√(7/6) = 1.0801` — шириной самой конструкции `E₈/2401`.
  Статус: численно (две независимые процедуры проекции поверх двух доказанных
  неравенств), точный рациональный сертификат — следующий шаг. Индекс ниже 9604
  в строгом режиме исключён исчерпывающим перебором (см. RESULTS.md).
- **Размерности 10–12: башня ламинаций E₈ с раскраской Γ = 3Λ.** Для
  вещественного множителя минимум `D` достигается на `3u` с минимальным `u`
  (минимальные векторы всегда релевантны по Вороному), откуда `D_min = 2λ₁` и
  `d = 2/ρ` — условие допустимости ровно `ρ = diam/λ₁ ≤ 2`. Ламинирование E₈ с
  сохранением `λ₁` даёт `diam²_{n+1} ≤ (3/4)·diam²_n + 1`, что остаётся ниже
  неподвижной точки 4 при всех `n ≥ 8`. Строго:
  `χ(ℝ¹⁰,[1,1.1795]) ≤ 3¹⁰`, `χ(ℝ¹¹,[1,1.1166]) ≤ 3¹¹`,
  `χ(ℝ¹²,[1,1.0755]) ≤ 3¹²`; неравенством является только рекурсия для радиуса
  покрытия, `λ₁` и `D_min` проверены напрямую (все векторы, две независимые
  процедуры проекции). Индекс `3ⁿ` при этом **оптимален среди подрешёток,
  содержащих `3Λ`**: скан всех `59 048` ненулевых классов `Λ/3Λ` при `n = 10`
  не оставил ни одного допустимого. Эйзенштейнов путь `7^{n/2}` в размерности 10
  закрыт (`ρ = (2/3)√7 > √(7/3)`), что вместе с `K₁₂` расширяет частичный
  отрицательный ответ на открытый вопрос 2 АБПР с ранга 6 на ранг 5.
- **Объёмный скрин Минковского** — строгая нижняя граница индекса для *любой*
  подрешётки данной родительской решётки: условие раскраски равносильно
  `Γ ∩ int K = {0}` для `K = 2(V₀ ⊕ R·B)`, откуда `k ≥ vol(V₀ ⊕ R·B)/det Λ`,
  и в замкнутой форме `k ≥ (1 + R·ωₙ^{1/n})ⁿ`. Раньше минимальность индекса
  устанавливалась только исчерпывающим перебором. Именно этот скрин показал,
  что размерность 9 стоит в 10.5 раза выше препятствия (все остальные — в
  1.4…4.0), то есть ей не хватало не оптимизации, а конструкции.
- **Кампания «ниже 45»** (CMA-ES по формам Грама с точным оценщиком +
  диагностика неотделимых векторов): при всех k = 31..44 порог не достигается
  (максимум d = 0.990 при k = 44). Свидетельством минимальности это **не**
  является: ровно та же сигнатура наблюдалась при k = 139 в ℝ⁵, где порог
  впоследствии был пройден до 132 (paper §sec:open, `audit-data/n8..n10`).
- Точные ширины запрещённых интервалов конструкций АБПР (arXiv:2112.13438) для
  4 ≤ n ≤ 9, тождество для эйзенштейновых решёток (реализует усиление из
  замечания 9 той же работы), уточнение таблицы Иванова (ℝ³).
- Масштабируемый метод для n ≥ 5 (CSP + min‑conflicts, безвершинный радиус
  покрытия; ядро на C++), **лестницы ширин ℝ⁵/ℝ⁶**.
- Хроника кампаний, численные фронтиры и честные статусы отрицательных
  экранов — в [RESULTS.md](RESULTS.md).

Скрипты и данные экспериментов больших размерностей —

## С чего начать

- Нужен только python и размерность 4 — берите **voronoi4d** напрямую.
- Нужна скорость или размерности 2/3/5/6 — собирайте **combigeo**.
- Хотите единый интерфейс с возможностью переключать движок и сверять
  результаты — используйте **chromatic** (он вызывает один из первых двух).

## Что нужно иметь

- **git** и **Python ≥ 3.10** — обязательно.
- Компилятор **C++17**, **CMake ≥ 3.20** и **Ninja** — только для `combigeo`
  (pybind11 подтянется автоматически при установке).
- **TeX Live** с поддержкой кириллицы — только чтобы пересобрать статью в
  [`paper/`](paper/README.md) (готовый PDF уже лежит там).

## Быстрая установка (всё сразу, для разработки)

```bash
git clone <URL-репозитория> Chromatic
cd Chromatic
python3 -m venv .venv && source .venv/bin/activate

pip install -e voronoi                 # voronoi4d (+ numpy, scipy, sympy)
pip install ./combigeo                 # combigeo (нужен компилятор C++; pybind11 подтянется)
pip install -e 'chromatic[dev]'        # фасад + pytest (кавычки обязательны в zsh)

python -c "import chromatic; print(chromatic.available_backends())"
# ['combigeo', 'voronoi4d']
```

> Для быстрого LLL в voronoi4d опционально: `pip install -e voronoi[fast]` (fpylll).

## Связь проектов

`chromatic` импортирует `voronoi4d` и/или `combigeo` как бэкенды (через
`importlib.util.find_spec`) — жёсткой зависимости нет, работает с любым доступным.
Бэкенд выбирается **явно** по имени: `chromatic.get_backend("combigeo")`.
В размерности 4 доступны оба, что позволяет независимую кросс-валидацию
(`chromatic.compare_backends`): combigeo использует GJK по вершинам, voronoi4d —
каскад проекций по граням; совпадение результатов подтверждает корректность.

## Теория (кратко)

Подробное обоснование — в [voronoi/docs/article.tex](voronoi/docs/article.tex).

- Решётка Λ задаёт периодическое разбиение ℝⁿ на ячейки Вороного.
- Подрешётка Γ индекса k разбивает Λ на k классов смежности — k цветов.
- Расстояние между одноцветными ячейками: D(v) = 2·dist(v/2, V₀) (лемма Иванова).
- Раскраска запрещает интервал расстояний с нормировкой d = D/diam(V₀); пригодна при d ≥ 1.
- Задача: для каждого k найти подрешётку с максимальным min_v D(v).

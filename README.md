# Chromatic — хроматическое число ℝⁿ через решётчатые разбиения Вороного

Набор из трёх взаимосвязанных проектов для исследования верхних оценок
хроматического числа евклидова пространства с запрещённым интервалом
расстояний (методология Л.Л. Иванова): пространство раскрашивается периодически
по подрешётке Γ ⊂ Λ, число цветов k = [Λ:Γ] = |det(M)|, а корректность
раскраски определяется нормированным запрещённым расстоянием d = D/diam(V₀) ≥ 1.

```
Chromatic/
├── voronoi/     — python-пакет voronoi4d (эталонная реализация, размерность 4)
├── combigeo/    — C++ ядро + python-модуль (pybind11), размерности 2…6
└── chromatic/   — над-проект: единый фасад над обоими бэкендами
```

## Статья и результаты

Основной итог исследования — статья **[`paper/chi4-45.tex`](paper/chi4-45.tex)**
(собирается в `paper/chi4-45.pdf`, `figures.py` строит иллюстрации):

- **χ(ℝ⁴) ≤ 45** (было 49) — раскраска решёткой общего положения, ключевое
  неравенство доказано в точной рациональной арифметике; плюс раскраска в 48
  цветов для более широкого интервала.
- **Свидетельство минимальности 45** — целевая кампания «ниже 45» (CMA-ES по
  формам Грама с точным оценщиком + диагностика неотделимых векторов): при всех
  k = 31..44 порог не достигается (максимум d = 0.990 при k = 44), препятствие
  той же природы, что и в ℝ⁵/ℝ⁶ (paper §sec:open, `audit-data/n8..n10`).
- Точные ширины запрещённых интервалов конструкций АБПР (arXiv:2112.13438) для
  4 ≤ n ≤ 9, тождество для эйзенштейновых решёток, уточнение таблицы Иванова (ℝ³).
- Масштабируемый метод для n ≥ 5 (CSP + min‑conflicts, безвершинный радиус
  покрытия; ядро на C++), **лестницы ширин ℝ⁵/ℝ⁶**.
- Вычислительное **свидетельство устойчивости** оценок 140 (ℝ⁵), 343 (ℝ⁶),
  1372 (ℝ⁷): не понижаются ни решётками общего положения, ни (в проверенных
  случаях) клеточными раскрасками.

Скрипты и данные экспериментов больших размерностей —
**[`audit-data/hd-2026-07/`](audit-data/hd-2026-07/README.md)** (с README, где
для каждого эксперимента указан результат и раздел статьи). Ранние аудит, план и
отчёт перенесены в [`archive/`](archive/) (предшествуют результату χ(ℝ⁴) ≤ 45).

## С чего начать

- Нужен только python и размерность 4 — берите **voronoi4d** напрямую.
- Нужна скорость или размерности 2/3/5/6 — собирайте **combigeo**.
- Хотите единый интерфейс с возможностью переключать движок и сверять
  результаты — используйте **chromatic** (он вызывает один из первых двух).

## Что нужно иметь

- **git** и **Python ≥ 3.10** — обязательно.
- Компилятор **C++17**, **CMake ≥ 3.20** и **Ninja** — только для `combigeo`
  (pybind11 подтянется автоматически при установке).
- **TeX Live** с поддержкой кириллицы — только чтобы пересобрать статью в
  [`paper/`](paper/README.md) (готовый PDF уже лежит там).

## Быстрая установка (всё сразу, для разработки)

```bash
git clone <URL-репозитория> Chromatic
cd Chromatic
python3 -m venv .venv && source .venv/bin/activate

pip install -e voronoi                 # voronoi4d (+ numpy, scipy, sympy)
pip install ./combigeo                 # combigeo (нужен компилятор C++; pybind11 подтянется)
pip install -e 'chromatic[dev]'        # фасад + pytest (кавычки обязательны в zsh)

python -c "import chromatic; print(chromatic.available_backends())"
# ['combigeo', 'voronoi4d']
```

> Для быстрого LLL в voronoi4d опционально: `pip install -e voronoi[fast]` (fpylll).

## Связь проектов

`chromatic` импортирует `voronoi4d` и/или `combigeo` как бэкенды (через
`importlib.util.find_spec`) — жёсткой зависимости нет, работает с любым доступным.
Бэкенд выбирается **явно** по имени: `chromatic.get_backend("combigeo")`.
В размерности 4 доступны оба, что позволяет независимую кросс-валидацию
(`chromatic.compare_backends`): combigeo использует GJK по вершинам, voronoi4d —
каскад проекций по граням; совпадение результатов подтверждает корректность.

## Теория (кратко)

Подробное обоснование — в [voronoi/docs/article.tex](voronoi/docs/article.tex).

- Решётка Λ задаёт периодическое разбиение ℝⁿ на ячейки Вороного.
- Подрешётка Γ индекса k разбивает Λ на k классов смежности — k цветов.
- Расстояние между одноцветными ячейками: D(v) = 2·dist(v/2, V₀) (лемма Иванова).
- Раскраска запрещает интервал расстояний с нормировкой d = D/diam(V₀); пригодна при d ≥ 1.
- Задача: для каждого k найти подрешётку с максимальным min_v D(v).

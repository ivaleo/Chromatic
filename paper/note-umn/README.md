Аннотация (рус.): Доказаны новые оценки χ(ℝ⁹) ≤ 9604 и χ(ℝ¹⁰) ≤ 45619. Доказательство основано на продуктовом правиле для ширин периодических решёточных раскрасок и точной ширине конструкции (3+ω)E₈ индекса 2401.

English metadata abstract: We prove the new bounds χ(ℝ⁹) ≤ 9604 and χ(ℝ¹⁰) ≤ 45619. The proof combines a product rule for the widths of periodic lattice colorings with the exact width of the index-2401 construction (3+ω)E₈; 45619 is the first bound in ℝ¹⁰ below the classical 3ⁿ.

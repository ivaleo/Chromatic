# note-umn/ — краткое сообщение для УМН

`note.tex` — «Новые верхние оценки хроматических чисел евклидовых пространств»:
одна теорема со всеми пятью новыми оценками χ(ℝ⁴) ≤ 43, χ(ℝ⁵) ≤ 132,
χ(ℝ⁷) ≤ 1029, χ(ℝ⁹) ≤ 7203, χ(ℝ¹⁰) ≤ 45619 (с интервалами). Состав:
п. 1 постановка и теорема; п. 2 критерий решёточной раскраски (доказан в тексте);
п. 3 четыре явные конструкции — рациональные матрицы Грама, подрешётки, число
фасет и вершин ячейки, точные diam², D², d — и описание конечной проверки в
рациональной арифметике; п. 4 продуктовое правило и планарная граница с
доказательствами, откуда 45619 аналитически.

Аннотация (рус.): Доказаны новые верхние оценки χ(ℝ⁴) ≤ 43, χ(ℝ⁵) ≤ 132,
χ(ℝ⁷) ≤ 1029, χ(ℝ⁹) ≤ 7203 и χ(ℝ¹⁰) ≤ 45619 (прежние 49, 140, 1372, 17253,
3¹⁰). Первые четыре даны явными рациональными решётками с проверкой в точной
арифметике, последняя следует из продуктового правила для ширин
решёточных раскрасок и ширины конструкции (3+ω)E₈ индекса 2401.

English metadata abstract: We prove the new upper bounds χ(ℝ⁴) ≤ 43,
χ(ℝ⁵) ≤ 132, χ(ℝ⁷) ≤ 1029, χ(ℝ⁹) ≤ 7203 and χ(ℝ¹⁰) ≤ 45619 (previously 49,
140, 1372, 17253, 3¹⁰). The first four come from explicit rational lattices
verified in exact arithmetic; the last follows from a product rule for the
widths of lattice colorings and the width of the index-2401 construction
(3+ω)E₈; 45619 is the first bound in ℝ¹⁰ below the classical 3ⁿ.

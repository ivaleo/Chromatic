# note-dan/ — краткое сообщение для «Докладов РАН»

`dan.tex` — «Новые верхние оценки хроматических чисел евклидовых
пространств» для журнала «Доклады Российской академии наук. Математика,
информатика, процессы управления» (англ. версия — Doklady Mathematics).
Оформление — официальный стилевой файл журнала `dan2e.sty` (копия
`DAN2E.STY` из `DanMath_for_Authors.zip`, sciencejournals.ru/journal/danmiup/;
не менять). Сборка: `latexmk -pdf dan.tex` → `dan.pdf`.

## Назначение (решение автора 15.09.2026)

Это **та же короткая статья, что и двухстраничный вариант**,
но для площадки с лимитом 25 000 знаков (~6 страниц) вместо двух страниц:
выбирается одна из двух площадок, состав один — все пять новых оценок.
Первая редакция от 14.09 (только аналитическая часть: тождество,
продуктовое правило, пол на E₈, без четырёх сертификатов) отменена автором
и сохранена лишь в истории git (коммит 5f17c91).

Что даёт запас объёма по сравнению с двухстраничным вариантом:

| Пункт | В `dan.tex` | В двухстраничном варианте |
|---|---|---|
| 1. Постановка и результат | теорема с пятью оценками и интервалами | четыре оценки (без 45619) |
| 2. Решёточные раскраски и ширина | критерий (2) и лемма о середине с доказательствами | то же, короче |
| 3. Проверка в точной арифметике | пять шагов протокола (фасеты, вершины, окно, разделение, запас) с обоснованием, роль плавающей точки | один абзац |
| 4. Четыре конструкции | те же данные, что в двухстраничном варианте (Q, подрешётки, число фасет/вершин, точные diam², D², d), плюс по фразе о симметрийном сужении поиска для 43 и о полноте списка вершин для 1029/7203 | те же данные |
| 5. Оценка в размерности 10 | планарная граница и лемма о произведении с доказательствами, вывод 45619; замечание: 9604 в ℝ⁹, 4·7¹² и 19·7¹² в ℝ²⁵, ℝ²⁶ | отсутствует |

Численные кандидаты (28812 и др.), лестницы, экраны и тождество в форме
равенства не включены — они остаются в статьях 1–2. Ссылок на
неопубликованные работы нет (правило п. 14); репозиторий — только в
подстрочном примечании.

## Что ждёт авторов

1. Выбор площадки для краткого сообщения.
2. Представление академика РАН (или подача с просьбой о представлении).
3. Аффилиации, УДК, данные для отдельной страницы (п. 4 правил).
4. Подтвердить формулировки разделов о финансировании и конфликте интересов.
5. Решить, выкладывать ли английскую версию (`../arxiv-en/`) на arXiv до
   подачи: правила Докладов препринты не упоминают, но п. 17 и 19 говорят
   о проверке на повторное опубликование — при сомнении спросить редакцию.

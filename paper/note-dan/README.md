# note-dan/ — краткое сообщение для «Докладов РАН»

`dan.tex` — «Новые верхние оценки хроматических чисел евклидовых
пространств» для журнала «Доклады Российской академии наук. Математика,
информатика, процессы управления» (англ. версия — Doklady Mathematics).
Оформление — официальный стилевой файл журнала `dan2e.sty` (копия
`DAN2E.STY` из `DanMath_for_Authors.zip`, sciencejournals.ru/journal/danmiup/;
не менять). Сборка: `latexmk -pdf dan.tex` → `dan.pdf`.

## Назначение (решения автора 15 и 16.09.2026)

Краткое сообщение со всеми пятью новыми оценками — **к публикации
рассматривается именно оно**. Первая редакция `dan.tex` от 14.09
(только аналитическая часть: тождество, продуктовое правило, пол на E₈, без
четырёх сертификатов) отменена автором и сохранена лишь в истории git
(коммит 66cbde7).

| Раздел | Содержание |
|---|---|
| 1. Постановка и результат | теорема с пятью оценками и интервалами; обзоры истории задачи — Райгородский (УМН 2001; Springer 2013; Contemp. Math. 2014), Боголюбский–Райгородский (Матем. заметки 2019) |
| 2. Решёточные раскраски и ширина | критерий (2) и лемма о середине с доказательствами |
| 3. Проверка в точной арифметике | пять шагов протокола (фасеты, вершины, окно, разделение, запас) с обоснованием, роль плавающей точки |
| 4. Четыре конструкции | Q, подрешётки, число фасет/вершин, точные diam², D², d; по фразе о симметрийном сужении поиска для 43 и о полноте списка вершин для 1029/7203 |
| 5. Оценка в размерности 10 | нижняя граница через проекцию на плоскость и лемма о произведении с доказательствами, вывод 45619; замечание: 9604 в ℝ⁹, 4·7¹² и 19·7¹² в ℝ²⁵, ℝ²⁶ |

Численные кандидаты (28812 и др.), лестницы, экраны и тождество в форме
равенства не включены — они остаются в статьях 1–2. Ссылок на
неопубликованные работы нет (правило п. 14); репозиторий — только в
подстрочном примечании.

## Что ждёт авторов

1. Представление академика РАН (или подача с просьбой о представлении).
2. Аффилиации, УДК, данные для отдельной страницы (п. 4 правил).
3. Подтвердить формулировки разделов о финансировании и конфликте интересов.
4. Решить, выкладывать ли английскую версию (`../arxiv-en/`) на arXiv до
   подачи: правила Докладов препринты не упоминают, но п. 17 и 19 говорят
   о проверке на повторное опубликование — при сомнении спросить редакцию.

# note-dan/ — краткое сообщение для «Докладов РАН»

`dan.tex` — «Точные ширины решёточных раскрасок евклидовых пространств:
тождество для эйзенштейновых решёток, продуктовое правило и оценка
χ(ℝ¹⁰) ≤ 45619» для журнала «Доклады Российской академии наук. Математика,
информатика, процессы управления» (англ. версия — Doklady Mathematics).
Оформление — официальный стилевой файл журнала `dan2e.sty` (копия
`DAN2E.STY` из `DanMath_for_Authors.zip`, sciencejournals.ru/journal/danmiup/;
не менять). Сборка: `latexmk -pdf dan.tex` → `dan.pdf`.

## Что публикуется и почему именно это (решение 14.09.2026)

Двухстраничный вариант краткого сообщения уже занят четырьмя явными
конструкциями с точными сертификатами (43/132/1029/7203). Правила Докладов
запрещают одновременную подачу одной рукописи в другой журнал и повторные
публикации, поэтому в Доклады отдана **аналитическая часть работы, не
пересекающаяся с двухстраничным вариантом** и не требующая вычислений:

| № | Утверждение | Откуда в комплекте |
|---|---|---|
| Теорема 1 | тождество D(αΛ) = 2λ₁·dist(α/2, H₁) для всех эйзенштейновых решёток; в частности D((3+ω)Λ)² = (7/3)λ₁² и D(mΛ) = (m−1)λ₁ | статья 2, §2 (thm:eis, cor:hexcell, prop:mult) |
| Следствие 1 | точные ширины √(7/6) всех конструкций 7^{n/2} (D₄, E₆*, E₈, Λ₂₄); K₁₂: 7⁶ в ℝ¹² недостижимо, зато 3¹² при ℓ < √(3/2) | статья 2, §2 |
| Теорема 2 | продуктовое правило: ширина произведения = (Σ dᵢ⁻²)^{−1/2} | статья 1, §4 (prop:product) |
| Теорема 3 | χ(ℝ¹⁰) ≤ 45619 и χ(ℝ²⁶) ≤ 19·7¹² при ℓ < √(217/214); χ(ℝ⁹) ≤ 9604 и χ(ℝ²⁵) ≤ 4·7¹² при ℓ < √(63/61) | статья 1, §4; статья 2, §5.4 |
| Теорема 4 | оболочечный пол: индекс ≥ 2401 на E₈ (равенство на (3+ω)E₈), ≥ 15 на ОЦК | статья 2, §5.3 (thm:e8opt, thm:a3opt) |

Все доказательства полные и элементарные (леммы о середине, о точке в
ячейке, инрадиусная, радиальный свидетель). Ссылок на неопубликованные
работы нет (правило п. 14): более сильная оценка 7203 в ℝ⁹ упомянута одной
фразой как результат авторов, публикуемый отдельно, без библиографической
ссылки; репозиторий — только в подстрочном примечании. Численные кандидаты
(28812 и др.) не упоминаются.

## Требования журнала (guid.pdf и journals.rcsi.science, сверено 14.09.2026)

| Требование | Состояние |
|---|---|
| ≤ 25 000 знаков с библиографией | ~20 400 знаков по `pdftotext` (включая дублирующий английский список литературы); 6 страниц стиля |
| ≤ 25 источников, самоцитирование ≤ 30 % | 8 источников, 1 самоцитирование (12,5 %) |
| аннотация ≤ 1000 знаков, без ссылок и аббревиатур | ~955 знаков |
| 3–10 ключевых слов | 9 |

| раздел журнала и УДК | «Математика», УДК 514.174.5+519.174 — **сверить с редакцией** |
| представление академиком РАН (п. 1–2) | **TODO** — `\presentedby{…}` / `\altpresentedby{…}`; допустима подача с просьбой передать академику |
| аффилиации, адреса, телефоны (отдельная страница, п. 4) | **TODO** — в тексте стоят заглушки «Москва» / МФТИ (по e-mail второго автора; подтвердить) |
| финансирование и конфликт интересов (п. 9–11) | разделы есть: «без финансовой поддержки», «конфликта нет» — подтвердить |

| лицензионные договоры (русская и английская версии) | при подаче |

Английские аннотация и ключевые слова в PDF стилем не печатаются (так же
в образце журнала) — они нужны редакции из исходника.

## Что ждёт авторов

1. Представление академика РАН (или подача с просьбой о представлении).
2. Аффилиации, УДК, данные для отдельной страницы (п. 4 правил).
3. Подтвердить формулировки разделов о финансировании и конфликте интересов.
4. Решить, выкладывать ли английскую версию (`../arxiv-en/`) на arXiv до
   подачи: правила Докладов препринты не упоминают, но п. 17 и 19 говорят
   о проверке на повторное опубликование — при сомнении спросить редакцию.
